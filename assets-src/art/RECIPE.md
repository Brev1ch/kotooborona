# Рецепт стиля — Кото-оборона

Эталон: огненный кот 1-го уровня, сгенерирован 14.10.2026 в SeaArt.
Остальные коты сделаны в Qwen правкой эталона, особенности каждого (закрытые глаза пара,
прищур болота и т. д.) оставлены намеренно как характер кота.
Все персонажи игры генерируются по этому рецепту, меняется только блок «Стихия».

## Промпт

Структура: [ОБЩЕЕ НАЧАЛО] + [СТИХИЯ] + [ОБЩИЙ КОНЕЦ].

**Общее начало:**
```
masterpiece, best quality, game asset, single character, cute chibi cat mage,
```

**Стихия (огонь — эталон):**
```
fire element, bright orange fur with red tips, big flame tuft on the head,
tiny red cape with a round amber brooch, small flame on the tip of the tail,
```

**Общий конец:**
```
big head, small round body, huge shiny eyes, happy confident smile,
sitting pose, full body, front three-quarter view, centered,
thick dark brown outline, flat cel shading, soft simple shapes,
vibrant saturated colors, clean vector style, mobile game character,
plain white background
```

**Negative prompt:**
```
realistic, photo, 3d render, detailed fur texture, noise, grain, texture,
paper texture, complex background, scenery, shadow on ground,
gradient background, text, watermark, signature, logo, multiple characters,
cropped, out of frame, extra limbs, extra tails, deformed, blurry, lowres,
wizard hat, crown, weapon, staff
```

## Остальные персонажи: Qwen

С 14.10.2026 SeaArt недоступен, поэтому персонажи делаются в Qwen правкой эталона:
загружается fire.png и отправляется одна инструкция «Edit this image: turn this fire cat into…».
Каждый новый персонаж делается от эталона, а не от предыдущего результата.
Инструкции для котов лежат в docs/CAT_PROMPTS.md.
Qwen рисует кремовый фон с текстурой, его убирает `npm run art`.

## Правила стиля

- Голова крупная, тело маленькое, глаза огромные, рот «w».
- Контур толстый, тёмно-коричневый, одинаковой толщины у всех.
- Заливка плоская, без шума и текстуры.
- Стихия видна по двум признакам: цвет шерсти + «хохолок» на голове
  (и тот же символ на кончике хвоста).
- Плащ цвета стихии с круглой брошью.
- Шляпы и короны нет: уровень кота показывает игра.
- Все персонажи (коты, мыши, герой) рисуются в спокойной позе, стоя или сидя, лицом к зрителю, без тени на земле: движение (дыхание, походку, выстрел, попадание, гибель) и тень даёт код.
- Проверка: картинка, уменьшенная до 64 px, должна читаться.

## Стихии (блок «Стихия»)

| Стихия | Шерсть | Хохолок и хвост | Плащ |
| --- | --- | --- | --- |
| Огонь (эталон) | ярко-оранжевая с красными кончиками | пламя | красный, янтарная брошь |
| Вода | насыщенно-голубая | капля воды | синий, аквамарин |
| Земля | шоколадно-коричневая | серый камень / галька | оливковый, изумруд |
| Воздух | светлая мятная | белый вихрь | белый с мятным краем, серебро |
| Пар | лавандово-белая, глаза закрыты | облачко пара | сиреневый, жемчуг |
| Лава | тёмно-багровая с огненными трещинами | капля лавы | чёрный с оранжевым краем, рубин |
| Гроза | лимонно-жёлтая | молния | фиолетовый, жёлтый камень |
| Лёд | бледно-ледяная голубая | ледяной кристалл / снежинка | голубой с инеем, кристалл |
| Болото | болотно-зелёная, хитрый прищур | лист с каплей / зелёный пузырь | буро-зелёный, янтарь |
| Песок | песочно-золотая | песчаный вихрь | бежевый, топаз |

У гибридов внутренняя сторона ушей окрашена в цвета двух исходных стихий.
