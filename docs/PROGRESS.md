### 14.10.2026 — обучение и первые встречи

- **Интерактивное обучение на Опушке** (`systems/Onboarding.ts`, `scenes/OnboardingOverlay.ts`): учит действием — всё, кроме цели, затемнено и не нажимается, рука показывает касание или перетаскивание, одна строка текста. Шаги: призвать кота → призвать ещё одного (стихия та же, пара гарантирована) → слить; первая волна ждёт эти три шага. Смешение — когда впервые есть два разных базовых кота и кристалл; метеор — когда заряд впервые полон (кнопка, затем прицел); на это время бой стоит. Один раз — флаг `onboarded` в сохранении (версия 8; кто проходил уровни, уже обучен). «Пропустить» — на экране, «Пройти обучение заново» — новое окно настроек в меню (шестерёнка). Новый игрок с первого уровня идёт сразу в бой, без снаряжения. Подсказки «призыв» и «слияние» первого уровня убраны — их заменило обучение.
- **Подсказки при первой встрече** (`scenes/hintBubble.ts`): пузырь на первом экране снаряжения, у первого готового сундука, подсказка про стройку — один раз за игру (`hintsSeen`, сохранение версии 9). Касаний не перехватывают. Карточка нового врага с обучением не пересекается: обучение на первом уровне, первая карточка — на третьем.
- **Проверки:** `npm run check` — 966 тестов; полный смоук — 35 из 35 (новые сценарии: обучение до конца; «Пропустить» и «Пройти обучение заново»); быстрый смоук теперь включает обучение нового игрока. `npm run build` без ошибок.
- **Архив для Яндекс Игр:** `pack/kotooborona-0.1.0.zip` — 919 КБ (без сжатия 1970 КБ, 70 файлов). Загружать: консоль → Черновик → Общее → Архив.

### 14.10.2026 — метеор, жизни, сюжет

- **Метеор** — заряд 0→100 % вместо перезарядки: копится со временем боя (на паузе стоит), между волнами сохраняется, в начале уровня пуст; бить можно только при полном. Заряд 110 с, у длинных уровней своё время (`meteorChargeTime`: Опушка 90, Старый дуб 125, Бурелом 150, Мельница и Лагерь 140, Мост 130). Урон 100 (×1,32 за волну, ×hpMult уровня), радиус 75. Снаряжение ускоряет заряд не сильнее чем до 0,72 времени — с лучшим снаряжением не больше трёх метеоров за уровень (страж в `Bot.test.ts`). Кольцо заряда у сферы героя и на кнопке, полный заряд — пульсация, свечение, звук `meteorReady`; касание при неполном — кнопка качается.
- **Жизни** — 3, сердечки в HUD; враг у ворот отнимает одну, король — три (`livesCost`). Звёзды: без потерь — 3, одна — 2, больше — 1. «Второй шанс» возвращает 2 жизни. Баланс всех уровней подобран ботом по доле побед.
- **Сюжет** — сценка перед каждым из 10 уровней (и при повторном прохождении) и после победы на 5-м и 10-м; черновик диалогов — `docs/STORY.md`.
