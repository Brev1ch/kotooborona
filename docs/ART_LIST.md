# Список арта

Файл собирает `npm run art` из манифеста `src/data/art.json`; руками не править.

Готово картинок: 21 из 55. Пока картинки нет, на её месте в игре рисунок кодом.

## Общие требования

- Исходник — png, имя и папка как в столбце «Файл», класть в `assets-src/art/`.
- Размер — в пикселях, это 2× от размера на экране. Исходник может быть крупнее: он уменьшается с сохранением пропорций.
- Фон прозрачный (кроме фонов уровней). Если прозрачности нет, фон должен быть светлым и ненасыщенным (белая или кремовая бумага): он убирается заливкой от краёв, белое внутри контура остаётся.
- Вырезку котов проверять по `assets-src/art/preview.png`: его пишет тот же `npm run art`.
- Прозрачные края обрезаются, остаток вписывается в размер по центру.
- После добавления файлов: `npm run art`, затем `npm run smoke` и снимки в `screenshots/`.

## Враги (11 из 12)

- Вид спереди, лицом к зрителю, в спокойной позе, без тени на земле. Стиль — в `docs/RECIPE.md`.
- Игра картинку не поворачивает: враг всегда стоит прямо, а идя влево, отражается по горизонтали. Походку, тень и попадания даёт код.
- Картинка квадратная, враг стоит по её нижнему краю; сторона — по размеру врага (`size` в `src/data/enemies.json`).
- Признак врага (сапоги, каска, посох, повязка, крылья, корона) должен читаться в размере на экране — он вдвое меньше картинки.
